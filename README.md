# Мониторинг сервера

Учебный прототип. Программа запускается на компьютере и показывает загрузку
процессора, занятую и свободную память, заполненность дисков, журнал и
оповещения. Страница открывается в браузере любого устройства той же локальной
сети. В промышленную эксплуатацию не входит и службы Windows не меняет.

## Состав

- `app.py` — опрос системы и выдача страницы, без веб-фреймворка
- `index.html`, `style.css`, `app.js` — страница
- `config.example.json` — образец настроек
- `config.json` — рабочие настройки, создаётся при первом запуске
- `monitor.log` — журнал, дописывается в конец

`config.json` и `monitor.log` в репозиторий не входят.

## Запуск

```
pip install -r requirements.txt
python app.py
```

Адрес появится в консоли. На этом компьютере страница открывается как
`http://127.0.0.1:8080`. С другого устройства локальной сети берётся адрес
вида `http://192.168.x.x:8080`. Порт наружу не пробрасывать.

Показатели читает один поток, по умолчанию каждые 5 секунд. Браузеры забирают
последний готовый снимок и не запускают повторное чтение дисков.

## Пороги

По умолчанию оповещение появляется, когда процессор или память выше 85%,
а диск заполнен больше чем на 90%. Цифры меняются на странице и сразу
записываются в `config.json`. Страницу для этого править не нужно.

Если связь со страницей пропала, на экране остаются последние цифры и
появляется надпись об этом. Ошибка чтения отдельного показателя не
останавливает программу: на карточке будет н/д, в журнале — текст ошибки.

## Ограничения

Входа и пароля нет. Программа принимает запросы только с локальных адресов
и только читает показатели. Письма, мессенджеры и звуковой сигнал не
используются: оповещение видно на странице и попадает в журнал.
Тома без буквы, диски без диска и сетевые диски в список не выводятся.
